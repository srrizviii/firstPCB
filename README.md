# First PCB – Eco-Car Onboarding PCB


A basic PCB designed in **KiCad 10.0** as my onboarding project for **UAlberta Eco-Car**. The goal was to learn the complete PCB workflow (schematic capture, footprint selection, layout, design rules, and fabrication outputs) before contributing to the team's electrical systems.

## Overview

Built without a specific purpose in mind, more of a general development board, with a USB-C connector, 4 push buttons, 10 configurable LEDs, connections for I2C, SPI, a mini OLED screen, and general purpose pins so external modules can communicate with the MCU (STM32F103C8Tx).
